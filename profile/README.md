# 🥖 A Kenyér

**Egy pékség saját szoftverei**

</div>

Itt készülnek azok a rendszerek, amelyek az A Kenyér pékség mindennapi munkáját segítik, a számlák nyilvántartásától a szerverig, amelyen mindez fut.

- **Vekni**: webes adminisztrációs felület számlákhoz, cégekhez, felhasználókhoz és jogosultságokhoz.
- **Ansible**: a Vekni szerverének automatizált, megerősített telepítése és üzemeltetése.
