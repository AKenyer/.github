# 🥖 A Kenyér

**Egy pékség saját szoftverei**

</div>

Itt készülnek azok a rendszerek, amelyek az A Kenyér pékség mindennapi munkáját segítik, a számlák nyilvántartásától a szerverig, amelyen mindez fut.

- **Adminisztráció**: webes felület számlákhoz, cégekhez, felhasználókhoz és jogosultságokhoz.
- **Üzemeltetés**: a szerver automatizált, megerősített telepítése és karbantartása.
